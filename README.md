# Alex Morgan — Cinematic Portfolio

A continuous storytelling-on-scroll portfolio built with Next.js, React, TypeScript, Tailwind CSS, GSAP ScrollTrigger, Framer Motion, Lenis, and Lucide.

## Run locally

```bash
npm install
npm run dev
```

Editable portfolio copy and sample work live in `src/data/portfolio.ts`. The desktop choreography is directed by `src/components/story/useStoryDirector.ts`; mobile and reduced-motion visitors receive a complete static narrative.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```
